# SONIC NEXUS 🔊🌌
### Interactive Audio-Visual Synthesizer & Kinetic Soundscape Suite

**SONIC NEXUS** is an immersive, high-performance web application combining real-time Web Audio synthesis with reactive 3D canvas visualizers and kinetic typography. Built entirely with vanilla web technologies, Tailwind CSS, and the HTML5 Canvas API with zero heavy external dependencies.

---

## ✨ Features & Visual Modules

### 1. 🎹 Web Audio Synthesizer Engine
* **What it is:** A multi-oscillator synthesizer producing lush ambient chords, rhythmic arpeggios, and cosmic sub-bass drones in real-time.
* **Presets:** Includes multiple soundscape presets (*Quantum Ambient Pad*, *Cybernetic Pulsar Pulse*, and *Deep Space Drone*) featuring 432 Hz Solfeggio tuning frequencies.
* **Controls:** Adjustable low-pass filter cutoff frequency, master volume, and beat reactivity sensitivity.

### 2. 🌀 Real-Time Audio Visualizer (3 Modes)
* **Spectrum Bars:** Dynamic frequency equalizer bars with multi-color gradients responding to audio wave activity.
* **Circular Pulsar:** Hypnotic radial frequency waveform ring expanding and pulsating to the rhythm.
* **Cyber Tunnel Warp:** Multi-ring perspective warp tunnel reacting instantly to bass pulsations.

### 3. ✍️ Kinetic Typography & Particle Field
* **Kinetic Typography:** Titles, subtitles, and lyrics scale, glow, and shift dynamically with mouse parallax movement and audio frequency beat detection.
* **Particle Field:** Interactive floating ambient particle dust grid that renders across the viewport.

---

## 🚀 Getting Started

No complex build steps, audio file assets, or package managers are required! 

1. Clone or download this project.
2. Open the `index.html` file in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Click **"START SOUND & VIBES"** on the introductory overlay to unlock browser audio permissions and experience the synthesizer.

---

## 🛠️ Built With

* **Web Audio API** for procedural real-time synthesis and frequency analysis.
* **HTML5 Canvas 2D** for high-performance visual rendering.
* **Tailwind CSS** for responsive layout and glassmorphism styling.
* **Google Fonts & FontAwesome** for typography and iconography.
* **Vanilla JavaScript (ES6+)** with zero external frameworks.
